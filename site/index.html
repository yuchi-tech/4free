一个镜像完成服务端、博客和客户端配置页

YC4free 适合部署到 DcDeploy：容器启动后自动生成节点参数，普通访问显示博客，隐藏路径输入密码后显示客户端配置。

运行模式 单容器
客户端协议 VLESS Reality
博客服务 Node HTTP

Data

部署数据

Xray 端口 443

用于 VLESS Reality TCP 连接，可通过 XRAY_PORT 调整。

网站端口 8080

博客和隐藏客户端配置页共用 Node HTTP 服务。

配置存储 /data

UUID、Reality key 和 shortId 持久化保存，重启不丢失。

健康检查 /ready

平台可通过该地址判断容器是否已经准备完成。
